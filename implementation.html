トップ/研究とエビデンス

Implementation

エビデンスと社会実装をつなぐ

研究により得た知見を、認知症予防・生活習慣病予防・フレイル予防に活用し、広く社会に浸透させる。それが、持続可能な高齢社会・地域社会づくりへの貢献につながります。

PDCA Cycle

研究と社会実装の好循環

研究結果を迅速に社会実装し、データを収集・分析した上で次なる研究へ活かす。神戸大学では、この強固なサイクルを構築しています。協議会はこの循環を、大学の外へ、全国へと広げる役割を担います。

  1. 研究・開発多因子介入の効果検証、新たな予防法の探索
  2. 社会実装コグニケアプログラムの地域・企業への展開
  3. データ収集・分析参加者の認知・身体データ、生活習慣データの蓄積
  4. 次なる研究へ効果的な介入方法の特定、個別最適化への応用

展開中の研究テーマ

多因子介入研究 認知機能評価AI開発 栄養・食品機能性 eスポーツ検証 フレイル予防 生活習慣病管理 社会的孤立対策 認知症診断応用AI

Interdisciplinary

総合大学の強みを活かした多分野連携

医学だけではなく、農学・保健学・人間発達環境学・システム情報学まで

神戸大学の認知症予防研究は、医学によるアプローチのみにとどまりません。農学、保健学、人間発達環境学、システム情報学など多岐にわたる研究科が成果を共有し、研究科と社会実装チームがシームレスに連携する体制となっています。

協議会は、この学内連携を、自治体・企業・医療介護機関・地域住民との連携へと広げます。

EVIDENCE

エビデンスの確立

多因子介入による認知機能向上効果を国内で初めて実証。

IMPLEMENTATION

社会実装志向

研究成果を地域で実践し、そのデータを次なる研究へ還元するサイクル。

COLLABORATION

多分野連携

医学・保健学・栄養学・運動科学・社会学の専門知を融合。

Words that travel

研究の言葉を、暮らしの言葉に翻訳する

「多因子介入」は研究の場では正確な言葉ですが、生活者には何をするのか見えず、「介入される」という受け身の印象を与えてしまいます。協議会は、相手に合わせて言葉を使い分けながら、同じエビデンスを社会に届けます。
