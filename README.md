# 100年脳・健康づくり推進協議会 公式サイト（たたき台）

NPO法人「100年脳・健康づくり推進協議会」（設立準備中）のWebサイトです。
専門知識がなくても、Claude Code に日本語で頼めば更新できるように作っています。

## このフォルダにあるもの

| ファイル・フォルダ | 役割 |
|---|---|
| `index.html` | トップページ（1st view・宣言・理事長メッセージ・各ページへの導線） |
| `about.html` | 設立の背景と趣旨（団体概要を含む） |
| `research.html` | 丹波研究とコグニケア |
| `implementation.html` | エビデンスと社会実装をつなぐ |
| `standard.html` | 100年脳スタンダードは「100年脳習慣」から |
| `infrastructure.html` | 健康寿命を支える新しい社会インフラを |
| `board.html` | 理事・役員名簿（準備中） |
| `join.html` | 100年脳スタンダードを共に社会のあたりまえに（賛助会員募集） |
| `journal.html` | 100年脳ジャーナル予告 |
| `news.html` | お知らせ |
| `contact.html` | お問い合わせ |
| `assets/style.css` | 全ページ共通の見た目（色・書体・レイアウト） |

| `README.md` | この説明書。人が読む |
| `CLAUDE.md` | Claude Code が読む説明書。用語ルールと更新の作法 |
| `_old/` | 以前の版（公開対象外） |

## サイトの見方（公開前）

ページ同士の行き来やメニューは、ファイルをダブルクリックで開くだけでは動かない場合があります。
Claude Code に「サイトをローカルで表示して」と頼むと、確認用のアドレスを用意します。

## 更新のしかた

1. このフォルダで Claude Code を開く
2. 日本語で頼む。例：
   - 「お知らせに『2027年5月○日 設立記念シンポジウムを開催します』を追加して」
   - 「理事長メッセージの本文を、添付の原稿に差し替えて」
   - 「役員名簿に副理事長の○○さん（所属△△）を追加して」
   - 「ヘッダーメニューに『よくあるご質問』を足して」
3. 表示を確認して、問題なければ「GitHubに保存して公開して」と頼む

## 公開の仕組み

- ファイルは GitHub（団体名義のアカウント）に保存し、GitHub Pages が自動で公開します
- 保存のたびに公開ページが更新されます。壊したときは「昨日の状態に戻して」で戻せます
- 独自ドメイン（候補：100nennou.jp）は取得後に接続します

## 引き継ぎのときに渡すもの

- 団体専用 Gmail のアドレスとパスワード（GitHub・ドメインの登録に使用）
- GitHub のリポジトリURL（またはこのフォルダ）
- 「Claude Code を開いて頼めば更新できる。詳しくは README を読む」の一言

## 未確定の項目（「仮」タグが付いている箇所）

- 団体名称：資料間で「協議会」「機構」「100年脳・健康づくり協議会」の揺れあり。現在は「100年脳・健康づくり推進協議会」で統一
- NPO宣言文（トップ、100〜200字）と理事長メッセージ本文・写真
- 理事・役員名簿、定款等の書類
- 所在地・所轄庁・設立予定日
- 問い合わせフォームの送信先（Googleフォームに接続予定）
- メールアドレス（ドメイン取得後に確定）
- 写真は説明資料から流用した仮のもの。正式公開前に差し替え
